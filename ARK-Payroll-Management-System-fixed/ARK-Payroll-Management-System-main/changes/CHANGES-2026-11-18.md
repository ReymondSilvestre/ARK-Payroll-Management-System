# ARK-Payroll – update of 18 Nov 2026

## How to install (2 minutes)
1. Replace the web files (index.html, css/, js/, assets/) on GitHub Pages with the ones in this zip.
2. Apps Script: paste the new `backend/Code.gs` over the old one (your `MY_DATABASE_URL` is already in it) → Deploy → Manage deployments → Edit → **New version**.
3. Open the web app and sign in. The FIRST request after deploying takes ~10-20 seconds (it creates the new tabs `Overtime File` and `Payslip Summary`); after that it is fast.
   The login screen should say "Code version: hr-fast-2026-11-18".
4. Optional, once from the Apps Script editor: run `installDailyBackup()` (nightly backup). The backup after each payroll is now scheduled by itself.

## What changed
- **Early time in / out** – Attendance check, DTR, attendance sheets. Uses the teacher's own Time in / Time out (Teacher Hours menu), then shifts, then the default hours. Filter "Early in / early out" and "Who: Teachers". Settings → Auto late & overtime to switch it off or set the minimum minutes. Report only, no deduction.
- **Payslip summary** (employee name · salary = net pay · signature) – new `Payslip Summary` tab in the main database (written at every save) and `PAYSLIP SUMMARY` tab in the backup spreadsheet (one boxed sign list per payroll run, with totals). In the app: Payslips → *Summary sheet* (printable) and *Summary (Excel)*.
- **HR user** – Users → Role: *HR (Leave and Overtime File only)*. HR sees only those two menus and the server refuses everything else; HR gets no salaries, no SSS/TIN numbers, no payroll settings. Role changes and Disable take effect at once.
- **Overtime File** now has its own tab (`Overtime File`), so HR and payroll can file at the same time without overwriting each other. Existing entries are moved there automatically on the first load.
- **Loan types**: Company Loan, SSS Salary Loan, SSS Calamity Loan, HDMF MPL, HDMF Calamity Loan. Old "SSS Loan" → SSS Salary Loan and "Pag-IBIG Loan" → HDMF MPL automatically; any other old type (Salary Loan, Emergency Loan, …) stays visible as "(old type)" until you pick a new one.
- **Faster saving** – see the notes in the chat reply (backup no longer rebuilt during the save, tabs checked once instead of on every request, block deletes, one-write employee saves, no full reload after saving).
- Safety: a new account can only be Payroll or HR (never Owner); two runs saved in the same second can no longer get the same ID; settings are refused with a clear message if they ever grow past the 50,000-character cell limit.
